# FLAN-T5 with LoRA for BioLaySumm: Medical Report to Layperson Summary

## Problem
This project fine-tunes a pretrained FLAN-T5 model to translate expert radiology reports into layperson-friendly summaries using the BioLaySumm dataset from the ACL 2025 BioLaySumm workshop (Subtask 2.1).

## Method
- **Model**: FLAN-T5 (encoder-decoder LLM)
- **Fine-tuning Strategy**: LoRA (Low-Rank Adaptation) for parameter-efficient training
- **Evaluation**: ROUGE scores (rouge1, rouge2, rougeL, rougeLsum)
